# Roadmap after 2.0.4
The 2.0.4 build deliberately avoids dead controls. Deeper features that should be implemented only with dedicated UX and tests are kept out of the visible interface for now: advanced drag-and-drop outfit composition, richer habit streak charts, full recurrence-rule editor, audio recording inside the diary, document previews for every file type, cloud sync, weather APIs and external calendar sync.

These are not required for the local core to function and no placeholder button is exposed for them.
