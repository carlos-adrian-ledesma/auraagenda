# GitHub Final — Runnable Source Status

AuraAgenda 2.0.3 GitHub Final Runnable contains the complete application source required to run the program from source on Windows.

Included:

- complete `app/` package and all pages;
- `launcher.py` and `app/main.py`;
- `INICIAR_AURAAGENDA.bat`;
- `run_windows.bat` and debug launcher;
- recovery launcher;
- runtime/build/dev requirements;
- assets;
- complete test suite;
- GitHub Actions and Dependabot;
- security, privacy, copyright and third-party documentation.

Not included:

- personal databases;
- user logs;
- backups;
- recovery kits;
- `.venv`;
- signing certificates/private keys;
- compiled Windows executable.

A standalone `.exe` is not claimed in this source package. The program is runnable through the supplied Windows source launcher after Python 3.11/3.12 is installed.
