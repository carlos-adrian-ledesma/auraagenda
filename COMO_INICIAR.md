# Cómo iniciar AuraAgenda

## Primera vez

1. Instalar Python 3.11 o Python 3.12 en Windows y habilitar la opción para agregar Python al PATH.
2. Descomprimir o clonar el repositorio.
3. Entrar en la carpeta `AuraAgenda`.
4. Hacer doble clic en `INICIAR_AURAAGENDA.bat`.
5. Esperar a que cree `.venv` e instale PySide6, cryptography y tzdata.
6. AuraAgenda se abrirá automáticamente.

## Siguientes usos

Usar `run_windows.bat` o volver a ejecutar `INICIAR_AURAAGENDA.bat`.

## Recuperación

Para restaurar un kit `.aurarecovery`, utilizar `RECUPERAR_AURAAGENDA.bat`.

## Si aparece un error

Abrir `run_debug_windows.bat` para conservar la consola y poder leer el mensaje técnico.
